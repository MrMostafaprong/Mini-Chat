# 💬 MiniChat

تطبيق مراسلة فورية (Real-time Chat) خفيف وسريع، يشبه تجربة واتساب، بواجهة عربية بالكامل (RTL). يدعم المحادثات الخاصة والمجموعات، مع مصادقة آمنة وبث فوري للرسائل عبر Socket.IO.

## ✨ المميزات

- 🔐 **مصادقة آمنة**: تسجيل دخول/خروج عبر JWT في httpOnly cookie، مع قفل تلقائي للحساب بعد محاولات دخول فاشلة متكررة
- 💬 **محادثات خاصة ومجموعات**: نظام موحّد يدعم النوعين، مع أدوار (admin/member) للمجموعات
- ⚡ **بث فوري**: كل رسالة تُبث لحظياً عبر Socket.IO فور حفظها، مع إعادة اتصال تلقائية عند انقطاع الشبكة
- 📎 **مشاركة الصور والملفات**: دعم إرسال صور (PNG/JPEG/WEBP/GIF) وملفات (PDF/DOC/DOCX/TXT) مع تحقق من النوع والحجم
- 👥 **إدارة المجموعات**: إنشاء مجموعات، ترقية/إزالة أعضاء، تعديل الاسم والصورة
- 🟢 **حالة الاتصال**: عرض المستخدمين المتصلين، ومؤشر "يكتب الآن..."
- 📄 **تحميل تدريجي للرسائل**: يتم جلب الرسائل صفحة تلو الأخرى (Pagination) بدل تحميل السجل الكامل دفعة واحدة
- 🛡️ **حماية شاملة**: Rate limiting، Helmet، CORS صارم، تحقق صارم من المدخلات، وحماية IDOR على كل العمليات الحساسة

## 🏗️ البنية التقنية

| الطبقة | التقنيات |
|---|---|
| **الواجهة الأمامية** | React 18 · Vite · React Router · Axios · Socket.IO Client |
| **الخادم** | Node.js · Express · Socket.IO · JWT · bcrypt |
| **قاعدة البيانات** | PostgreSQL (مع امتدادي `pgcrypto` و `citext`) |

## 🚀 التشغيل محلياً

### المتطلبات

- Node.js 18 أو أحدث
- PostgreSQL 14 أو أحدث

### 1. إعداد قاعدة البيانات

```bash
createdb minichat
psql -d minichat -f database/schema.sql
```

### 2. إعداد الخادم (Server)

```bash
cd server
npm install
cp .env.example .env
```

افتح ملف `.env` واضبط القيم التالية على الأقل:

- `DB_NAME`, `DB_USER`, `DB_PASSWORD` — بيانات الاتصال بقاعدة البيانات
- `JWT_SECRET` — نص عشوائي طويل وآمن (يمكن توليده بالأمر `openssl rand -hex 64`)

ثم شغّل الخادم:

```bash
npm run dev     # وضع التطوير (مع إعادة تشغيل تلقائية)
# أو
npm start       # وضع الإنتاج
```

الخادم سيعمل افتراضياً على `http://localhost:5000`.

### 3. إعداد الواجهة الأمامية (Client)

```bash
cd client
npm install
npm run dev
```

الواجهة ستعمل افتراضياً على `http://localhost:5173`.

افتح المتصفح على هذا العنوان، أنشئ حساباً جديداً، وابدأ الدردشة! 🎉

## 🔒 ملاحظات أمنية للنشر (Production)

- استخدم قيمة قوية وعشوائية لـ `JWT_SECRET`، ولا تشاركها أبداً
- فعّل `DB_SSL=true` إذا كانت قاعدة البيانات تدعم اتصالات مشفّرة
- إذا كان الخادم خلف reverse proxy (Nginx، Cloudflare، إلخ)، اضبط `TRUST_PROXY` في `.env` حتى يعمل الحد من معدل الطلبات (rate limiting) بشكل صحيح
- تأكد من ضبط `CORS_ORIGINS` على نطاق (domain) الواجهة الأمامية الفعلي فقط
